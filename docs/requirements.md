# 能量流水账 - 需求规格文档

## 项目概述

一款运行在浏览器手机端的能量流水账软件。帮助用户直观看到"无需求"模式对自己能量的实际消耗，通过连续记录日常活动的能量变化，发现哪些付出是真正快乐的，哪些是习惯性迎合在悄悄消耗自己。

## 核心功能

### 1. 能量记录
- 记录项包含：
  - 时间（自动获取）
  - 我做了什么（文本 + 活动标签）
  - 和谁在一起（文本 + 人物标签）
  - 事后我的能量：😊 (+)、😐 (0)、😔 (-)
  - 简短感受备注
- 每条记录有唯一 UUID 标识，绝不重复
- 支持连续记录，自动标记记录天数

### 2. 快速记录
- 预设常用活动类型标签（帮人做事、社交聚会、独处休息、工作任务等）
- 预设常用人物标签（家人、朋友、同事、自己等）
- 一键选择，减少输入成本

### 3. 记录管理（CRUD）
- 手动添加新记录
- 编辑已有记录的任意字段
- 删除记录（需确认）

### 4. 搜索与筛选
- 按日期范围筛选
- 按能量状态筛选（+ / 0 / -）
- 按活动标签筛选
- 按人物标签筛选
- 关键词搜索

### 5. 数据导入导出
- 导出全部记录为 CSV 文件
- 导出全部记录为 Excel (.xlsx) 文件
- 批量导入 CSV 数据

## 页面结构

### 首页 `/`
- 今日能量总览（正/负能量条数、净能量值）
- 本周能量趋势概览（迷你图表）
- 最近 5 条能量记录
- 连续记录天数打卡

### 记录页 `/record`
- 大按钮快速添加新记录
- 常用活动类型一键选择
- 常用人物标签一键选择
- 能量状态表情符号选择（😊 / 😐 / 😔）
- 简洁输入框
- 历史记录列表（支持编辑/删除）

### 洞察页 `/insights`
- 本周/本月能量趋势图表（ECharts）
- 正负能量活动占比饼图
- 不同人物的平均能量值排行
- 不同活动类型的平均能量值排行
- 自动生成能量分析报告文本
- 指出消耗型 vs 滋养型活动和人际关系

### 我的页 `/me`
- 每日记录提醒时间设置（跳过 MVP）
- 备份数据（导出 JSON 到本地）
- 恢复数据（导入 JSON）
- 导出全部记录（CSV / Excel）
- 使用说明
- 练习引导

## 额外功能

### 7 天周报
连续记录满 7 天时，自动生成专属一周能量洞察报告：
- 对比"你以为的付出"和"实际的能量消耗"
- 引导用户不带批判地观察自己

### 能量急救提示
当用户连续多天负能量占比过高时，给出简单的自我关怀建议文案。

## 数据与隐私
- 所有数据完全存储在用户浏览器本地（localStorage）
- 不上传任何服务器
- 绝对保护用户隐私

## 设计风格
- 简洁、治愈、直观
- 主色调：柔和绿色或淡蓝色
- 浅色模式
- 避免复杂装饰元素和多余动画
- 适配 iPhone 所有主流屏幕尺寸（375px - 430px 宽度）
- 移动端触控友好（按钮 44px+ 点击区域）
