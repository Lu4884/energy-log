# 能量流水账 - 开发执行计划

## 分阶段开发策略

每个阶段完成后进行验证，确保功能正确再进入下一阶段。不一次性做太多。

---

## Phase 1 — 项目脚手架

**目标**：可以本地运行，有底部导航，4 个页面占位。

- [ ] Vite + React + TypeScript 初始化
- [ ] 安装依赖：react-router-dom, echarts, xlsx, lucide-react
- [ ] 配置 CSS 变量和全局样式
- [ ] 创建 Layout 组件（底部导航）
- [ ] 创建 4 个页面占位组件
- [ ] 配置 React Router 路由
- [ ] 验证：`npm run dev` 正常运行，4 个 Tab 可切换

---

## Phase 2 — 数据层

**目标**：数据模型和本地存储可用。

- [ ] 定义 TypeScript 类型 (Record, Settings)
- [ ] 实现 localStorage 读写封装 (get/set/remove)
- [ ] 实现 RecordsContext（全局状态）
- [ ] 实现 CRUD hooks (useRecords)
- [ ] 创建预设标签常量
- [ ] 编写单元验证（console 测试存储读写）

---

## Phase 3 — 记录页

**目标**：可以添加、查看、编辑、删除记录。

- [ ] 能量状态选择器 (😊/😐/😔)
- [ ] 活动输入框 + 活动标签选择器
- [ ] 人物输入框 + 人物标签选择器
- [ ] 备注输入框
- [ ] 保存按钮 + 表单验证
- [ ] 记录列表展示
- [ ] 编辑功能（点击记录弹出编辑模式）
- [ ] 删除功能（确认后删除）

---

## Phase 4 — 首页

**目标**：今日总览和基本信息展示。

- [ ] 今日能量总览卡片（正/中/负计数、净能量）
- [ ] 本周趋势迷你图
- [ ] 最近 5 条记录列表
- [ ] 连续打卡天数显示
- [ ] 空状态引导（无记录时）

---

- [ ] 正负能量占比饼图

- [ ] 人物平均能量排行
- [ ] 自动分析报告文本生成
- [ ] 7 天周报检测与展示
- [ ] 能量急救提示
